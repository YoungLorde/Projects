## Tier Sub-Level System
Every tier has 4 sub-levels in order:
1. **Beginner** — Basic upgrades, marginal improvement
2. **Advanced** — Significant jump, new component categories
3. **High** — Near-peak, qualitative difference from tier below
4. **Peak** — Maximum, special upgrade required for next tier
