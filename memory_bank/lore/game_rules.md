# THE GRAND GAME — CORE RULES

## Fundamental Laws
1. Every sentient being across all universes is enrolled — no opt-out
2. Every player receives a System Interface upon entry
3. Every player begins with a starter vehicle appropriate to their species
4. Players must survive, collect resources, research, upgrade, and level up
5. Player-vs-player combat is legal and encouraged by the Game
6. No permanent safe zones — all safe zones must be built, earned, and defended
7. Death is permanent — vehicle, resources, and loot scatter for collection
8. Rules may change without warning — the Game updates its own laws
9. The Game observes — player actions influence future events
10. Hidden achievements exist — the Game rewards undisclosed behaviors

## System Events
- **Global Events**: Affect all players in a zone/region
- **System Announcements**: Universe-wide information broadcasts
- **Universal Events**: Cross-universe events (rare, catastrophic)
- **Forced Quests**: Mandatory participation, severe penalties for refusal

## Tier Milestone Notifications
- Every 10 tiers: Visible to same-universe players (anonymous)
- Every 50 tiers: Visible across entire Prime Universe
- Every 100 tiers: Visible across ALL universes simultaneously

## Resource Points (RP)
- Universal Game currency for instant upgrades
- Acquired through: kills, quests, discoveries, crafting, trading, territory, events
- All upgrades require either raw materials OR RP

## Hidden Mechanics (Revealed Gradually)
- System has preference hierarchy — rewards certain behaviors more
- Unique adaptations receive hidden bonuses
- System tracks player psychology and tailors challenges
- "Anomaly" classifications for pattern-breaking players
- Deeper code layers beneath the player-facing System
