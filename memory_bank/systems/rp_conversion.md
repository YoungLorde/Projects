# RP CONVERSION — ABILITY REFERENCE

## Core Rules
- **EXCLUSIVE to Mohamed Vance** — no other player in any universe
- **SECRET** — no external signs, System does not announce it
- Converts any physical matter into Resource Points
- Rate scales with: material rarity, complexity, energy density, dimensional origin
- Can convert selectively or wholesale

## Mystery Arc

- This mystery is a slow-burn undercurrent across the entire series
- Partial reveal at end of Book 1

## Security Protocols (Mohamed's Rules)
1. Never convert in the open
2. Never convert when other players can observe
3. Use vehicle interior for all conversions when possible
4. If conversion is detected, deny and redirect
5. Kill witnesses if necessary (escalating response)
