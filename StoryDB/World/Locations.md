## TYPE LEGEND

| Type | Description |
| ------ | ------------- |
| Residence | Where a character lives |
| Workplace | Where a character works |
| Office | Company office |
| Facility | Industrial, research, or military base |
| Virtual | VR universe / simulation |
| Planet | Planetary body |
| City | Urban settlement |
| System | Stellar system |
| Galaxy | Galactic-scale location |
| Universe | Multiverse-level location |

---

## TABLE NOTES

- **Population:** Current known population. Use `0` for unpopulated or planned, `?` for unknown.
- **Status:** Active / Planned / Abandoned / Destroyed / Hidden / Public / Obsolete.
- **Owner / Faction:** Who controls or owns the location.
- When a location expands or changes ownership, add a new row for the new phase/version.

---

> Append new locations as new rows. Use `Registry.md` to assign the next `LOC-` ID.
