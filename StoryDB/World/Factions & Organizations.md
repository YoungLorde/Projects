## TYPE LEGEND

| Type | Description |
| ------ | ------------- |
| Company | Business entity |
| Government | Nation-state or ministry |
| Empire | Terran Empire or subordinate |
| Species | Alien or human species group |
| AI | Artificial intelligence faction |
| Entity | Abstract/powerful entity (e.g., the System) |
| Cult | Religious/ideological group |
| Criminal | Underground organization |

## TABLE NOTES

- **Leader:** Current leader or head of the faction.
- **Members:** Known member count (or key named members).
- **Territory:** Primary territory or base.
- When a faction evolves (e.g., Vance Global becomes the Terran Empire), add a new row for the new phase; do not overwrite.

---

> Append new factions as new rows. Use `Registry.md` to assign the next `FACT-` ID.
