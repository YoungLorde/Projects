## TABLE NOTES

- **Trust A→B:** How much Entity A trusts Entity B.
- **Trust B→A:** How much Entity B trusts Entity A.
- **Relationship Type:** Romantic, Family, Mentor, Ally, Employer, Rival, Antagonist, etc.
- **Status:** Active / Strained / Broken / Secret / Dead / Dormant.
- Update rows when a relationship shifts (e.g., a betrayal lowers trust, a death marks it Dead). Do not delete rows; update the Status column and Ch Last Updated.
