## TABLE NOTES

- **Type:** Protagonist / Supporting / Antagonist / NPC / Cameo / Faction.
- **Status:** Active / Inactive / Not Introduced / Not Created / Dead / Missing / Destroyed / Obsolete.
- **Cultivation Rank:** Per `Reference/Canon/Mechanics.md` (0 = Mortal Preparation, 1 = Mortal Foundation, etc.).
- **Lifespan:** Use base+pioneer values from Mechanics; update when rank advances.
- **Faction:** Primary affiliation at this point in the story.
- **Notes:** Height, voice quirks, fatal flaws, secrets, PIONEER status, etc.

> Append new characters as new rows at the bottom. Never insert in the middle. Use `Registry.md` to assign the next `CHAR-` ID.
