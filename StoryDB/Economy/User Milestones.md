## TABLE NOTES

- **Total Users:** Cumulative user count for the product.
- **Delta:** Change in users from the previous milestone.
- **Region / Scale:** `Local`, `Regional`, `National`, `Global`, `Planetary`, `Galactic`, `Universal`.
- **First-use bonus:** 10-17 SP per new unique user, exact value fluctuates per user, awarded immediately on first meaningful engagement. No wave or milestone bonuses. Each user milestone should be reflected in the `SP Ledger.md`.
- **Passive SP/hr formula:** `UserCount × 0.00000013 × RankMultiplier`.
- When a product is launched or reaches a milestone, add a new row.
