## TABLE NOTES

- **SP Cost:** Cost in System Points (if purchased from the Shop). Mark `N/A` for Mohamed's inventions.
- **Source:** `System Shop`, `Mohamed's Invention`, `R&D`, `VR Research`, `Construction`, `Reverse-Engineered`.
- **Dependencies:** Prior tech IDs that must exist first.
- **Required Rank:** Minimum cultivation rank to use (if applicable).
- **Prototype:** In-story date or chapter when the prototype is first demonstrated.
- **Production:** In-story date or chapter when production/scaled deployment begins.
- **Status:** Planned / Prototype / Active / Obsolete / Superseded / Classified.
- When a tech version is upgraded, add a **new row** (do not overwrite the old one). This preserves the Mark-by-Mark history.
- **Renumbering note:** The old draft had duplicate TECH-001…006 IDs across the active and future tables. Active techs keep TECH-001…006; future techs have been renumbered to TECH-007…032 to avoid collisions.
