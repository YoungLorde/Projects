## TABLE NOTES

- **Holder:** Character or entity that has the skill. Use `All Humanity` for species-wide traits.
- **Source:** `Innate`, `System Shop`, `Natural`, `Rank Advance`, `Inherited`, `Technique`, `R&D`, etc.
- **Cost (SP):** Leave blank or `N/A` for non-Shop skills.
- **Status:** Active / Not Active / Planned / Obsolete / Sealed.
- When a skill levels up or a new holder gains it, add a new row (do not overwrite). This tracks the progression history.
