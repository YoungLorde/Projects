# STORY CONSISTENCY CHECKER AGENT

## Purpose

Pre-chapter validation system that reads the previous 5 completed chapters and cross-references all tracking agents to ensure consistency, law compliance, and narrative continuity before the next chapter is written.

---

## MANDATORY PRE-WRITING CHECKLIST

### Step 1: Read Previous 5 Chapters

**Files to Review:**

1. Most recently completed chapter (N-1)
2. Chapter N-2
3. Chapter N-3
4. Chapter N-4
5. Chapter N-5

**What to Extract:**

- Final SP balance (SECRET - only Mohamed/Danielle)
- Final USD revenue (PUBLIC - tracked by staff)
- User count milestones
- Cultivation levels (Rank, Level, Percentage)
- Lifespan status
- Key character status
- Technology acquired/activated
- Karma events seeded/realized
- Major purchases made
- End notes summary

### Step 2: Cross-Reference CURRENCY_AGENT

**Verification Points:**

- SP balance matches ledger in CURRENCY_AGENT
- USD revenue is mathematically consistent ($100,000 = 1 SP conversion)
- Passive income calculation verified: User_Count × 0.00000013 × Rank_Multiplier
- Initial wave calculations correct for user milestones
- Purchase costs match astronomical scale table
- No SP mentioned by non-authorized characters (LAW CHECK)
- USD figures public and tracked by appropriate characters

**VIOLATION CHECK:**

- NO character except Mohamed/Danielle mentions SP
- NO character tracks SP balance
- NO mention of System Shop to outsiders
- USD tracking is public and visible to all appropriate characters

### Step 3: Cross-Reference TIMELINE_AGENT

- Chapter date is sequential and logical

### Step 4: Cross-Reference CULTIVATION_AGENT

## USAGE WORKFLOW

### Before Writing Each Chapter:

1. **Run Consistency Check** on previous 5 chapters
2. **Generate Report** with all verification points
3. **Review Discrepancies** - CRITICAL issues must be resolved
4. **Update Agents** if cumulative tracking needs adjustment
5. **Receive PASS status** before proceeding to write
6. **Proceed with chapter writing** using verified baselines

### After Writing Each Chapter:

1. **Update all tracking agents** with new chapter data
2. **Verify end notes match** agent records
3. **Flag any new karma events** seeded
4. **Confirm law compliance** maintained throughout
5. **Archive consistency report** with chapter file

## EMERGENCY PROTOCOLS

### If Critical Law Violation Detected:

1. **STOP** - Do not proceed with new chapter
2. **IDENTIFY** - Pinpoint exact violation and chapter
3. **ASSESS** - Determine if fix requires rewrite or retcon
4. **CORRECT** - Fix violation in existing chapter
5. **VERIFY** - Re-run consistency check
6. **PROCEED** - Only after PASS status achieved

### If SP Balance Mismatch:

1. Check passive income calculation
2. Verify conversion events recorded
3. Confirm purchase costs match astronomical table
4. Recalculate from Chapter 1 if necessary
5. Update all affected agent records
6. Document correction in log

### If Character Inconsistency:

1. Review character's last appearance
2. Check relationship agent status
3. Verify timeline positioning
4. Ensure motivation continuity
5. Update character profile if needed
6. Flag for narrative attention
