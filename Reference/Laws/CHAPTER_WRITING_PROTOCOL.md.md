# CHAPTER WRITING PROTOCOL

## Standard Operating Procedure for "The Rise of the Terran Empire"

---

## PRE-WRITING REQUIREMENTS (MANDATORY)

### Step 1: Guide Review (30 minutes)

- Read Master Story Guide current Arc section
- Review Paramount Laws (Secrecy, Fog of Discovery, Invention Mandate)
- Check Genre Lock (Sci-Fi/Cultivation Hybrid)
- Verify Chapter Target Word Count (5,500-15,000 words)

### Step 2: Continuity Review (30 minutes)

- Read previous 10 chapters in sequence
- Note ending date of Chapter N-1
- Note cultivation levels at end of Chapter N-1
- Note SP balance at end of Chapter N-1
- Note character locations at end of Chapter N-1
- Note active technologies at end of Chapter N-1
- Note ongoing conflicts/subplots from previous chapters

### Step 3: Agent Check (15 minutes)

- Check Timeline Agent - verify date progression
- Check Currency Agent - verify SP balance
- Check Cultivation Agent - verify rank/level
- Check Technology Agent - verify available tech
- Check World Agent - verify global state
- Check Relationship Agent - verify character states

### Step 4: Planning (15 minutes)

- Define chapter's narrative goal
- Identify key scene locations
- List characters present
- Note technology to introduce or advance
- Plan cultivation progress for chapter
- Identify karma events to seed

### Opening (500-800 words)

- **Hook:** Immediate engagement - action, mystery, or character moment
- **Setting the Scene:** Location, time, atmosphere
- **Character State:** Current emotional/physical state of POV character
- **Chapter Goal:** What must be accomplished this chapter

### Middle (4,000-12,000 words)

- **Scene 1:** Primary action/dialogue (1,500-3,000 words)
- **Scene 2:** Secondary action/development (1,500-3,000 words)
- **Scene 3:** Tertiary action/climax build (1,500-3,000 words)
- **Scene 4+:** Additional scenes as needed for narrative

### Ending (500-800 words)

- **Climax/Resolution:** Chapter's main event resolves
- **Consequence:** Immediate fallout
- **Setup:** Hook for next chapter
- **Date Stamp:** (REQUIRED) Current date displayed

## WRITING STANDARDS

### Dialogue

- **Mohamed:** Modern, professional but not stiff, occasionally humorous, age-appropriate (26-28)
- **Danielle:** Energetic, witty, modern, mischievous but brilliant, technical jargon when appropriate
- **Supporting Cast:** Distinct voices, avoid generic dialogue
- **Rule:** Every line of dialogue should reveal character or advance plot

### Description

- **Technology:** Detailed but accessible, explain function not just appearance
- **Cultivation:** Sensory details - how energy feels, physical sensations
- **Locations:** Establish atmosphere, use all five senses
- **Action:** Clear, visceral, easy to follow

### Pacing

- **Action Scenes:** Short paragraphs, rapid progression
- **Dialogue Scenes:** Mix of action beats and conversation
- **Exposition:** Broken into digestible chunks, never walls of text
- **Cultivation:** Balance technical detail with character experience

### Consistency Requirements

- **SP Tracking:** Every purchase must be logged, balance must be accurate
- **Cultivation Tracking:** Progress must follow established rates
- **Date Tracking:** Must progress logically from previous chapter
- **Technology:** No anachronisms, build on what's established
- **Character:** Actions must match established personality

## POST-WRITING REQUIREMENTS (MANDATORY)

### Step 1: Self-Review (30 minutes)

- Word count check: 5,500-15,000 words
- Read chapter aloud for flow
- Check for repeated phrases (use search)
- Verify date is at end of chapter
- Verify cultivation data is accurate

### Step 2: Consistency Check (30 minutes)

- Cross-reference previous 10 chapters for contradictions
- Verify SP calculations
- Verify cultivation progression
- Verify technology availability
- Verify character knowledge (what they know vs don't know)

### Step 3: Agent Updates (15 minutes)

- Update Timeline Agent with new date
- Update Currency Agent with SP changes
- Update Cultivation Agent with progress
- Update Technology Agent with new tech
- Update Relationship Agent with character developments
- Update Karma Agent with seeded events

### Step 4: Documentation (15 minutes)

- Add chapter gist to Master Index
- Update Master Story Guide with any new elements
- Log any new characters introduced
- Log any new technologies introduced
- Note any world-building additions

## REDUNDANCY CHECK PROTOCOL

### Search Terms to Check

1. Chapter opening phrases - ensure unique
2. Character introduction phrases - ensure unique
3. Technology descriptions - don't repeat from previous
4. Emotional beats - avoid recycling same reactions
5. Exposition dumps - break up with action/dialogue

### Tools

- Use file search to find repeated phrases
- Read previous 3 chapters before writing to avoid echoing
- Keep a "used phrases" log for major descriptions

## QUALITY METRICS

### Minimum Requirements

- Word count: 5,500+ words
- Date stamp: Present and accurate
- Cultivation data: Complete and accurate
- SP balance: Mathematically correct
- Character development: At least one character advances
- Technology: At least mentioned or advanced
- Karma event: At least one butterfly effect seeded

### Quality Targets

- Word count: 7,000-10,000 words (sweet spot)
- Scene count: 3-5 distinct scenes
- Dialogue ratio: 30-40% of chapter
- Character moments: Each major character has至少 one moment
- World building: New detail added
- Foreshadowing: At least one setup for future payoff
