# WORD COUNT AGENT

## Accurate Body-Text-Only Word Count Tracking

### Excludes: End Notes, Headers, Metadata Blocks, Agent Check Sections

---

## COUNTING PROTOCOL

### What COUNTS Toward Word Count

1. All narrative prose (descriptions, actions, scenes)
2. All dialogue (including dialogue tags)
3. All internal monologue/thoughts
4. All scene transitions (--- dividers NOT counted)
5. Chapter titles (NOT counted)

### What Does NOT Count

1. Header metadata blocks (between `# Chapter X` and first narrative paragraph)
2. End Notes sections (from `## CHAPTER END NOTES` to file end)
3. Cultivation Status blocks (if standalone at chapter end before End Notes)
4. Date stamps at chapter conclusions (e.g., `**Date: January 01, 2026**`)
5. System notification blocks (e.g., `**MISSION COMPLETE**`) — these DO count if integrated in narrative
6. Agent check sections or TODO markers

### Measurement Method

Total File Words

- Header Block Words (Date through Word Count Target)
- End Notes Words (## CHAPTER END NOTES through file end)
- Isolated Date Stamp Words  
= TRUE BODY WORD COUNT

### Target Standards

- **Per Chapter:** 13,000-15,000 body words
- **Minimum:** 12,000 body words
- **Maximum:** 16,000 body words
- **Tolerance:** +/- 3%
- **Arc Average:** 13,500+ body words per chapter

### Verification Checklist

Before marking chapter COMPLETE:

- Calculate body word count using exclusion method
- Verify count is within 12,000-16,000 range
- If below 12,000: Expand scenes, add sensory detail, deepen dialogue
- If above 16,000: Trim redundant exposition, tighten descriptions
- Record verified word count in end notes (e.g., `**Verified Body Word Count:** 14,247 words`)
