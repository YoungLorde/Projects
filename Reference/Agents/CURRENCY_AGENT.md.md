### Purpose

Systematically calculates the worth of System-purchased knowledge based on transformative impact, scarcity, and utility across 31 arcs and 3100+ chapters.

### Value Formula

Knowledge Value (SP) = Base × Impact × Scarcity × Complexity × Era Multiplier

Where:

- Base = 100 SSP (foundation unit)
- Impact = 1-10^30 (civilizational to cosmic change factor)
- Scarcity = 1-10^24 (uniqueness factor)
- Complexity = 1-10^18 (understanding difficulty)
- Era Multiplier = 1× to 10^24× (temporal context across eons)

### Passive Income Calculation

Passive SP/hour = User_Count × 0.00000013 × Rank_Multiplier

- Rank: 1 (Multiplier: 10)

### Initial Wave Calculation

Initial Wave SP = New_Users × Average_SP_Per_User  
Average_SP_Per_User = Random(10, 17)

Example (Chapter 5):

- New Users: 1,000
- Average SP: 15
- Initial Wave: 1,000 × 15 = 15,000 SP

### USD to SP Conversion (ONE-WAY ONLY)

**CRITICAL: SP is NEVER obtained directly from sales or revenue. It is ONLY acquired through the System's conversion interface.**

Conversion Formula: SP_Gained = Revenue_USD / 100,000

Process:

1. Real-world revenue (USD) accumulates from software sales, mining, investments
2. Mohamed accesses System interface (secret, only he/Danielle can see)
3. System converts USD to SP at fixed rate: $100,000 = 1 SP
4. USD is consumed in conversion (one-way only - SP never converts back)
5. SP is added to secret balance (invisible to all external observers)

Example:

- Software revenue: $5,000,000,000 USD (public, tracked by accountants)
- Mohamed converts: $5,000,000,000 / 100,000 = 50,000 SP (secret, System only)
- Result: Public shows $5B revenue, Secret shows +50,000 SP
