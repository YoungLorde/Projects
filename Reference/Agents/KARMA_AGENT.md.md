## PURPOSE

Tracks all seeded future events (karma), narrative payoffs, foreshadowing, and story debts across 3000+ chapters. Ensures satisfying narrative cohesion and callback moments.

---

## KARMA DEFINITIONS

### Karma Event Types

1. **Foreshadowing:** Hint of future event
2. **Setup:** Preparation for future plot point
3. **Seed:** Introduction of element that grows
4. **Debt:** Unresolved element requiring payoff
5. **Callback:** Reference to previous event
6. **Payoff:** Resolution of seeded element

### Karma Categories

1. **Character Karma:** Personal arcs, relationships, betrayals, redemptions
2. **Technology Karma:** Early tech becomes important later
3. **Political Karma:** Decisions with future consequences
4. **Military Karma:** Defense preparations, weapons, conflicts
5. **Economic Karma:** Financial decisions, investments
6. **Mystical Karma:** Cultivation events, mana stones, Aether

## KARMA VALIDATION RULES

### 1. Every Seed Must Grow

If you plant a seed (karma event), it must eventually pay off  
No abandoned plot threads without justification  
Dormant periods allowed, but payoff must come

### 2. Payoff Must Match Setup

Small seeds → Small payoffs  
Large seeds → Large payoffs  
Character karma → Personal resolution  
Tech karma → Application or consequence

### 3. Timing Matters

Immediate karma: Payoff within 10 chapters  
Short-term: Payoff within 100 chapters  
Medium-term: Payoff within 500 chapters  
Long-term: Payoff by end of story

### 4. Callback Quality

Callbacks should feel satisfying, not forced  
Reader should remember the seed (or be reminded)  
Payoff should exceed setup in impact  
Multiple seeds can combine for larger payoff
