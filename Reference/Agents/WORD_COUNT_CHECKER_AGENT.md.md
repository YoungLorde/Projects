## CRITICAL RULES

### 1. WHAT COUNTS TOWARD WORD COUNT

**INCLUDE (Story Content):**

- Narrative text (prose, descriptions, dialogue, action)
- Character thoughts and internal monologue
- Scene descriptions and setting details
- Dialogue between characters
- All story events and plot progression

**EXCLUDE (Metadata/Headers):**

- Chapter title line ("# Chapter 53: Title")
- All **Date:** fields
- All **Location:** fields
- All **Cultivation:** fields
- All **Lifespan:** fields
- All **Secret Reserves:** fields
- All **USD Revenue:** fields
- All **Users:** fields
- All **Key Characters:** fields
- All **Major Development:** fields
- All **Chapter Word Count Target:** fields
- The "---" separator lines
- **EXCLUDE (End Notes):**
- All "## CHAPTER END NOTES" sections
- **Word Count:** line at end
- All bullet points in end notes
- All **Cultivation Progress:** sections
- All **Key Events:** sections
- All **Next Chapter Setup:** sections

### 2. WORD COUNT TARGET VERIFICATION

**Chapter 53 Target:** 8,800 words (story content only)  
**Acceptable Range:** 8,500 - 9,100 words (±3% tolerance)

**Chapter 54 Target:** 8,900 words (story content only)  
**Acceptable Range:** 8,600 - 9,200 words (±3% tolerance)

**Chapter 55-100 Targets:** Variable per chapter (8,000 - 9,500 typical)  
**Acceptable Range:** ±3% of stated target

### 3. VERIFICATION FORMULA

Total Document Words

- Header Section Words (Date through Chapter Word Count Target)
- Separator Lines (---)
- End Notes Section Words  
= ACTUAL STORY WORD COUNT

**Target Check:**

- IF actual_story_words < (target - 3%): **FAIL - ADD CONTENT**
- IF actual_story_words > (target + 3%): **FAIL - TRIM CONTENT**
- IF within ±3%: **PASS - SUBMIT**

### 4. COMMON SHORTFALL AREAS

**If under word count, expand:**

- Scene descriptions (add sensory details)
- Character reactions (internal thoughts, emotions)
- Dialogue (conversations, debates, planning)
- Technical explanations (how things work, why decisions made)
- Action sequences (step-by-step detail)
- Strategic planning (contingencies, considerations)
- Aftermath/reflection (consequences, implications)

### 5. VERIFICATION CHECKLIST

Before submitting ANY chapter:

- Count total document words
- Subtract header section words (~150-200 words)
- Subtract end notes section words (~300-500 words)
- Verify story content is within ±3% of target
- If short: Add narrative content, NOT padding
- If long: Trim unnecessary passages, NOT critical plot
- Final check: Story word count meets target
